# WBCS — Answer Key Archive

## Purpose

This directory preserves official WBCS answer keys by examination cycle.

---

# 1. Answer-Key Lifecycle

The archive must distinguish:

- provisional/initial answer key;
- objections/corrections where officially published;
- final answer key.

Never overwrite an earlier answer key.

---

# 5. Research Use

Answer keys may support:

- answer verification;
- examination analysis;
- candidate study tools;
- research;
- historical examination tracking.

They must not be used to infer:

- cutoff;
- vacancy;
- final merit;
- selection;
- candidate eligibility.

Those require separate official evidence.

---

# 6. Copyright Handling

Do not reproduce the complete official answer-key document inside public research text.

Store the official document and record a concise description.

---

# 7. Production Rule

The website may expose:

    Answer Key Available
    Date Published
    Final Answer Key Available

The application should link to the official document rather than presenting an altered copy as an official document.
