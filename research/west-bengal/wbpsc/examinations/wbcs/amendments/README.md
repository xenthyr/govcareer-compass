# WBCS — Amendments, Corrigenda and Important Notices

## Purpose

This directory contains official changes to an existing WBCS examination cycle.

It must preserve the chronology of changes rather than replacing the original advertisement.

---

# 1. Amendment Types

Store:

- corrigendum;
- qualification amendment;
- vacancy amendment;
- age amendment;
- reservation amendment;
- application amendment;
- certificate-upload notice;
- edit-window notice;
- examination-date notice;
- centre notice;
- syllabus amendment;
- scheme amendment;
- other important official notices.

---

# 2. Chronology Rule

For each document record:

- publication date;
- affected examination;
- previous position;
- amended position;
- effective date;
- affected candidates;
- source ID.

---

---

# 4. Storage Convention

Example:

    wbcs-2024-edit-window-2026-01-02.pdf
    wbcs-2024-preliminary-notice-2026-05-14.pdf

---

# 5. Conflict Rule

If an amendment contradicts an earlier advertisement:

    latest applicable official amendment
             >
    earlier conflicting instruction

However, the original must remain archived.

---

# 6. Production Rule

The production database should contain the current effective value.

The research archive should contain:

    original
    +
    amendment
    +
    final interpretation

Never delete the original.
