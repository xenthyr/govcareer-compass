# WBCS — Advertisements Archive

## Purpose

This directory contains official WBCS recruitment advertisements and associated official advertisement documents.

---

# 1. Required Documents

At minimum investigate and preserve:

- WBCS Examination 2024 advertisement;
- later advertisement amendments;
- corrigenda;
- vacancy-related amendments;
- application-related notices;
- subsequent recruitment-cycle advertisements;
- historical advertisements required for comparison.

---

---

# 3. Storage Convention

Store the downloaded original file with a stable name.

Example:

    wbcs-2024-advertisement-2025-11-14.pdf

Do not rename it later merely for style reasons.

---

# 4. Advertisement Extraction

When a document is archived, record:

- advertisement number;
- document title;
- publication date;
- examination year;
- affected posts;
- eligibility;
- age;
- reservation;
- language;
- physical standards;
- pay;
- examination stages;
- important conditions.

---

# 5. Evidence Rule

The PDF is the primary evidence.

Do not modify the original PDF.

If a corrected advertisement appears:

    original
       +
    corrigendum
       +
    corrected conclusion

must all be preserved.

---

# 6. Production Rule

Information extracted from an advertisement may be promoted into production data only after:

- source verification;
- field-level review;
- conflict checking;
- schema validation.
