# GovCareer Compass — West Bengal Source Register

## 1. Purpose

This document defines the canonical source registry for the West Bengal research layer.

A source ID is an internal stable identifier.

It must point to an actual source.

A source ID must never be created merely because a production record requires one.

---

# 2. Source Classes

Each source belongs to one of:

- OFFICIAL_CURRENT
- OFFICIAL_HISTORICAL
- OFFICIAL_RULE
- SECONDARY
- ESTIMATE
- NOT_VERIFIED

# 9. Source Verification Rules

For every source:

- URL must be recorded exactly as found;
- title must reflect the actual document;
- publication date must not be invented;
- effective date must not be invented;
- source class must be explicit;
- relevance must be recorded;
- confidence must be recorded.

If an official source cannot be accessed:

    status = NOT_VERIFIED

Do not substitute a guessed URL.

---

# 10. Claim-Level Source Mapping

A source should state what it supports.

Example:

    SRC-WBPSC-WBCS-2024
        → WBCS eligibility
        → Bengali requirement
        → WBCS post list
        → WBCS pay level
        → police-service physical requirement

Do not assume a source supports unrelated facts simply because it concerns the same department.

---

# 11. Conflicting Sources

If two sources disagree:

1. identify both sources;
2. compare publication dates;
3. determine whether one superseded the other;
4. identify whether they refer to different cadres;
5. determine whether the difference is due to recruitment cycle;
6. record the conflict;
7. select the better-supported current value;
8. preserve the older value in historical research.

---

# 12. Source Confidence

### HIGH

Current primary official recruitment or rule source.

### MEDIUM_HIGH

Official historical source that appears still structurally relevant.

### MEDIUM

Official department information where exact recruitment applicability is unclear.

### LOW

Reputable secondary source.

### ESTIMATE

Analytical value.

### NOT_VERIFIED

Insufficient public evidence.

---

# 13. Source Register Maintenance

Whenever a new source is found:

1. assign stable source ID;
2. record exact organisation;
3. record exact title;
4. record exact URL;
5. classify source;
6. record publication/effective dates;
7. record supported claims;
8. record confidence;
9. update the appropriate production `sources.json`.

Never reuse an unrelated source ID.

---

# 14. Official Source Policy

GovCareer Compass should prefer:

    official notification
        >
    official service/recruitment rule
        >
    official gazette/order
        >
    official departmental page
        >
    official annual report
        >
    reputable secondary source
        >
    estimate

The lower a source appears in this hierarchy, the less it should be relied upon for hard eligibility or legally significant claims.
