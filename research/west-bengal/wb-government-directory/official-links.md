# 18. West Bengal Recruitment Research Rule

For a recruitment URL:

1. verify that the URL is official;
2. record it in the source register;
3. identify publication date;
4. identify relevant recruitment cycle;
5. identify current status;
6. preserve historical URL when historically relevant.

---

# 19. URL Integrity Rules

Never:

- invent a URL;
- alter an official URL to make it look cleaner;
- assume `.gov.in` is sufficient proof;
- use an unrelated department URL for a post;
- replace an unavailable historical source with a guessed URL.

If a source is known but its current official URL cannot be safely verified:

    URL = NOT_VERIFIED

# 21. Source-to-Claim Rule

Each production source should identify which claims it supports.

Example:

    SRC-WBPSC-WBCS-2024

supports:

- qualification
- Bengali requirement
- service/post list
- pay level
- physical requirements where stated
- examination structure

It does not automatically support:

- current HRA
- current quarter availability
- actual take-home salary
- practical family-life score

Those require separate evidence/analysis.

---

# 22. Official Link Maintenance

Review official links:

- before every major research release;
- whenever a government portal changes;
- whenever a recruitment authority changes its domain;
- when a broken-link check fails.

When a URL changes:

1. preserve old URL if historically relevant;
2. add new URL;
3. update `sources.json`;
4. update this file;
5. update `CHANGELOG.md`;
6. do not destroy historical evidence.

---

# 23. Production Source Mapping
